## Tasks 2–8: the 7 distributions

Follow the Batch A templates: closed-form → `rayleigh.ts`; iterative 1-D → `weibull.ts`/`gamma.ts`; iterative 2-D & reciprocal-delegation → `cauchy.ts`/`frechet.ts`. Every module: `type XParams` alias + one `p as XParams` narrowing per density + the FittedParams-DTO comment; named constants (no magic literals); `fit()` validates support + degeneracy throw; a **convention-guard test using ASYMMETRIC params** (a symmetric/standard point is slot-blind). Each task also adds the `DistributionName` entry, the `distributions/index.ts` registry line, the `sampling.ts` case, an `expectSamplerMatchesQuantile` guard in `sampling.test.ts`, and the `gen_fixtures.py` `build_<name>` + `BUILDERS` entry. `digamma`/`trigamma`/`gammaln` are imported from `@stdlib/math-base-special-*` (already deps via gamma/weibull).

### Task 2: Lévy — closed-form, k=1, CLOSED_FORM_NAMES

**MLE (closed-form, unique):** location fixed `mu = 0`; `c = data.length / Σ(1/xᵢ)` (harmonic mean). **Support x > 0 STRICT** (`if (data.some(v => v <= 0)) throw 'levy requires all x > 0'` — note `<= 0`, NOT Rayleigh's `< 0`: at x=0, `1/x` diverges and x=0 is outside the open support). Then `if (!(Number.isFinite(c) && c > 0)) throw 'levy: degenerate or non-finite scale'`. `MIN_SAMPLE_SIZE = 1`. **Params** `{c}` → `logpdf(x, LEVY_LOCATION, c)`, `cdf`, `quantile` with `LEVY_LOCATION = 0` (named const, like Fréchet's m); sampler `levySampler.factory(LEVY_LOCATION, c, {seed})`. **gate:** add `DistributionName.Levy` to `CLOSED_FORM_NAMES`. **Sampler guard:** median/IQR (no moments).

Convention guard: pdf `f(x;0,c)=√(c/2π)·exp(−c/2x)/x^{3/2}`; for c=2, x=1: `logpdf(1,{c:2}) === 0.5*Math.log(2/(2*Math.PI)) - 1 - 1.5*Math.log(1)` = `0.5*ln(1/π) − 1`. cdf(x)=erfc(√(c/2x)); a known value. fit test: `levy.fit([1,2,4])` → `c = 3/(1/1+1/2+1/4) = 3/1.75 ≈ 1.714` (assert exact). Degeneracy: `levy.fit([0,1,2])` throws (x≤0).

`build_levy` (gen_fixtures): analytic `c = n/Σ(1/x)`; `rv = stats.levy(loc=0, scale=c)`; `fixed = {"c": float(c)}` (IDENTITY — scipy levy `scale` == c; verified to 1e-14, do NOT invert). Mode A `form="closed-form"`, `params = {"c": c}`, `modeA.logLik = log_lik(data, stats.levy(loc=0, scale=<scipy.levy.fit(arr, floc=0) scale>))` — the INDEPENDENT scipy.fit LL floor (scipy ≈ analytic−1e-5). positive datasets.

### Task 3: Chi-Squared — iterative 1-D, k=1, LL-only

**MLE:** scale/loc fixed (2/0); fit `df` by 1-D Newton on `g(k)=ln2 + digamma(k/2) − meanLog(x)` (strictly increasing → unique root), `g'(k)=0.5·trigamma(k/2)`. Seed `df0 = mean(x)` (E[χ²]=k). Damp `k←k/2` on non-positive/non-finite step; reuse `MAX_NEWTON_ITERATIONS`/`NEWTON_REL_TOL`. Support x>0. `MIN_SAMPLE_SIZE=1`; guard `data.some(v=>v<=0)` → throw. **Params** `{df}` → `logpdf(x, df)`, `cdf(x, df)`, `quantile(p, df)`; sampler `chisquareSampler.factory(df, {seed})`. **Sampler guard:** moment. Convention guard: note quantile arg order is `(p, df)` — assert `quantile(0.8, {df:1}) ≈ 1.642`.

`build_chisquare`: Mode-A reference ANALYTIC (the digamma Newton in numpy — scipy.chi2.fit under-converges); `modeA.logLik` from the INDEPENDENT `stats.chi2.fit(arr, floc=0, fscale=1)` LL floor (BOTH floc=0 AND fscale=1 — chi² has no real loc/scale); `form="iterative"`, LL-only. positive datasets.

### Task 4: Chi — iterative 1-D, k=1, LL-only

**MLE:** scale fixed 1; fit `k` by 1-D Newton on `g(a)=digamma(a) − target` with `a=k/2`, `target=2·meanLog(x) − ln2`, `g'(a)=trigamma(a)` (>0, unique). Seed `k0 = mean(x²)` (E[X²]=k). Damp toward positivity. Support x>0; guard `v<=0`. `MIN_SAMPLE_SIZE=1`. **Params** `{k}` → `logpdf(x, k)` etc.; sampler `chiSampler.factory(k, {seed})`. **Sampler guard:** moment. `build_chi`: scipy `chi.fit(arr, floc=0, fscale=1)`; Mode-A analytic Newton + scipy LL floor; `form="iterative"`. positive.

### Task 5: Inverse Gamma (Pearson 5) — iterative 1-D via reciprocal-Gamma, k=2, LL-only

**MLE (reciprocal-Gamma identity, like Fréchet→Weibull):** `X~InvGamma(α,β) ⇔ 1/X~Gamma(shape=α, rate=β)`. So `import { gamma } from './gamma'`, fit `w = gamma.fit(data.map(x => 1/x))`, then **`shape = w.shape`, `scale = w.rate`** (= 1/w.scale — the gamma fit's RATE, NOT its scale). Support x>0; guard `v<=0` → throw; gamma.fit throws on degenerate reciprocals. `MIN_SAMPLE_SIZE=2`. **Params** `{shape, scale}` → `logpdf(x, shape, scale)` (beta=SCALE slot, passed DIRECTLY — opposite of gamma's rate), `cdf`, `quantile`; sampler `invgammaSampler.factory(shape, scale, {seed})`. **Sampler guard:** median/IQR (mean exists only for α>1, variance for α>2). `build_invgamma`: scipy `invgamma.fit(arr, floc=0)` (floc=0 ONLY — scale is REAL); map `shape=a, scale=scale` (IDENTITY on scale); `form="iterative"`, LL-only. Convention guard: pdf `β^α/Γ(α)·x^{−α−1}·e^{−β/x}`; for α=0.5,β=1,x=2: `logpdf(2,{shape:0.5,scale:1}) ≈ -2.112`. positive.

### Task 6: Cosine (raised cosine) — iterative 2-D with hard support barrier, k=2, LL-only

**THE LOAD-BEARING TRAP (mapping):** `@stdlib` support is `[mu − s, mu + s]`; scipy support is `[loc − π·scale, loc + π·scale]`. So **`@stdlib s = π · scipy_scale`** — in `gen_fixtures` map `mu = loc`, `s = math.pi * scale`. Emitting `scale` directly is a silent gate failure (verified: scipy.pdf == `(1/(2s))(1+cos(π(x−mu)/s))` only with `s = π·scale`).

**MLE:** 2-D over (μ, s) maximizing `Σ ln[(1/2s)(1 + cos(π(x−μ)/s))]` subject to the **HARD barrier `s > max|x − μ|`** (else LL=−∞) enforced on EVERY iteration. Score: `d/dμ: Σ (π/s)·sin(θ)/(1+cos(θ)) = 0`; `d/ds: −n/s + Σ (πd/s²)·sin(θ)/(1+cos(θ)) = 0` with `d=x−μ, θ=πd/s`. **Robust seed (load-bearing):** `μ0=mean(x)`; `s0 = max( sd/√(1/3 − 2/π²) , 1.05·max|x−μ0| )` (the MoM `Var=s²(1/3−2/π²)` widened so the seed support contains all data). Newton/coordinate-descent with step-halving that keeps `s > max|x−μ|`. Degeneracy: zero spread → throw `'cosine: degenerate (zero spread)'`. `MIN_SAMPLE_SIZE=2`. **Params** `{mu, s}` → `logpdf(x, mu, s)` etc.; sampler `cosineSampler.factory(mu, s, {seed})`. **Sampler guard:** moment.

`build_cosine`: **must SEED scipy** (default unseeded `cosine.fit` hits LL=−∞ on skewed data) and NOT fix loc/scale (both real): `mu0=np.mean(x); scale0=max(np.std(x)/sqrt(pi**2/3−2), np.max(np.abs(x−mu0))/pi*1.05); loc,scale = stats.cosine.fit(x, loc=mu0, scale=scale0)`; **`fixed={"mu":float(loc), "s":float(math.pi*scale)}`** (the π factor!); `rv = stats.cosine(loc=loc, scale=scale)`; `form="iterative"`, LL-only. Convention guard (asymmetric): pick μ=2,s=3,x=2.5 and assert `logpdf` equals the hand-written `ln((1/(2*3))*(1+cos(pi*0.5/3)))`.

### Task 7: Beta Prime (Pearson 6) — iterative 2-D, k=2, LL-only

**MLE:** 2-D Newton on the digamma score (strictly concave → unique): `g_a = mean(ln x) − [ψ(a) − ψ(a+b)]`, `g_b = −mean(ln(1+x)) − [ψ(b) − ψ(a+b)]`; Hessian `H_aa=−n[ψ'(a)−ψ'(a+b)]`, `H_bb=−n[ψ'(b)−ψ'(a+b)]`, `H_ab=n·ψ'(a+b)` (neg-def). Step `−H⁻¹g`, halve on `a≤0`/`b≤0`. Seed: MoM (clamp `b0>2`, `a0>0`; fall back `a0=b0=2` on zero variance). Support x>0; guard `v<=0`. `MIN_SAMPLE_SIZE=2`. **Params** `{alpha, beta}` (pure shapes) → `logpdf(x, alpha, beta)` etc.; sampler `betaprimeSampler.factory(alpha, beta, {seed})`. **Sampler guard:** median/IQR. `build_betaprime`: scipy `betaprime.fit(arr, floc=0, fscale=1)` (BOTH fixed — @stdlib betaprime is shape-only); map `alpha=a, beta=b`; `form="iterative"`. positive.

### Task 8: Beta — iterative 2-D, k=2, LL-only, (0,1) data

**MLE:** 2-D Newton (strictly concave → unique). `L1=mean(ln x), L2=mean(ln(1−x))`; `g1=ψ(a+b)−ψ(a)+L1`, `g2=ψ(a+b)−ψ(b)+L2`; `H11=ψ'(a+b)−ψ'(a)`, `H22=ψ'(a+b)−ψ'(b)`, `H12=ψ'(a+b)` (per-obs, ×n); `det=H11·H22−H12²>0`; step `da=−(H22·g1−H12·g2)/det`, `db=−(−H12·g1+H11·g2)/det`; halve on `a≤0`/`b≤0`. MoM seed from `m=mean, v=var`: `a0=m(m(1−m)/v−1)`, `b0=a0(1−m)/m` (fallback `a0=b0=1` if degenerate). **Support (0,1):** `if (data.some(v => v <= 0 || v >= 1)) throw 'beta requires all 0 < x < 1'`; zero-variance → throw. `MIN_SAMPLE_SIZE=2`. **Params** `{alpha, beta}` → `logpdf(x, alpha, beta)` etc.; sampler `betaSampler.factory(alpha, beta, {seed})`. **Sampler guard:** moment (but seed the guard with (0,1) params, e.g. `{alpha:2, beta:3}` — the sampler↔quantile check is moment-free anyway). `build_beta`: scipy `beta.fit(x, floc=0, fscale=1)` (BOTH fixed); map `alpha=a, beta=b`; `form="iterative"`; uses the **unit_interval datasets** (Task 1). Convention guard: asymmetric `{alpha:2, beta:5}` at x=0.3.
