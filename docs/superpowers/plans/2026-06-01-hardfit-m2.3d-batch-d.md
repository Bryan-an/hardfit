**Goal:** Introduce the engine's first **general-purpose numerical optimizer** (a vendored, pure-TS, deterministic Nelder–Mead minimizer) and add the first four families that need genuine multi-parameter MLE — **Student's t (3-param), Fisher–Snedecor F (2-param), Inverse Gaussian / Wald (2-param), Nakagami-m (2-param)** — growing the catalog **24 → 28**.

**Architecture:** A new domain-agnostic `src/engine/optimize.ts` minimizes `f: R^n → R` to a tolerance tighter than the parity gate; families reparameterize their MLE into unconstrained space (`log σ`, `log df`, …) and call it. Inverse Gaussian has a **closed-form** MLE (no optimizer). Nakagami reduces exactly to the **Gamma MLE on `x²`** (reuses gamma's 1-D Newton). All four are `kind: 'continuous'` → the existing EDF (KS/AD/CvM) + equiprobable-χ² GoF path, kind-aware bootstrap (full GoF resampling), and the scipy parity gate apply unchanged in shape — only new fixtures + a documented iterative-param-diagnostic skip-set are added.

**Tech Stack:** TypeScript engine (pure, no DOM/React/Comlink). New `@stdlib` packages: `stats-base-dists-t-{logpdf,cdf,quantile}`, `random-base-t`, `stats-base-dists-f-{cdf,quantile}`, `random-base-f`, `stats-base-dists-normal-logcdf`. Reused already-vendored: `stats-base-dists-betaprime-logpdf` (F density), `stats-base-dists-normal-cdf`, `random-base-normal`, `random-base-uniform`, `random-base-gamma`, `stats-base-dists-gamma-{cdf,quantile}`, `math-base-special-{gammaln,digamma,trigamma}`. ### Load-bearing `@stdlib` argument conventions (do not transpose)
- `t-logpdf(x, v)` / `t-cdf(x, v)` take **(value, df)**; `t-quantile(p, v)` takes **(prob, df)** — prob first. The standard t is loc=0/scale=1; the module does its own location-scale wrap (mirror `cauchy.ts`).
- `betaprime-logpdf(x, alpha, beta)` — F density route: `logpdf_F(x; d1, d2) = betaprimeLogpdf(d1*x/d2, d1/2, d2/2) + Math.log(d1/d2)`. **VERIFIED matches `scipy.f.logpdf` to ~1e-14.** Do **not** use `f-pdf` + `Math.log` (tail underflow → spurious −Inf; and `f-logpdf` does not exist on npm).
- `f-cdf(x, d1, d2)` / `f-quantile(p, d1, d2)` — d1 = numerator df, d2 = denominator df. **F is asymmetric** (`logpdf(2;5,12) ≠ logpdf(2;12,5)`, VERIFIED) → the convention-guard test must use `d1 ≠ d2` at a non-unit `x`.
- `gamma-cdf(x, alpha=shape, beta=RATE)` and `gamma-quantile(p, alpha, beta=RATE)` and `random-base-gamma.factory(alpha, beta=RATE, {seed})` — **rate, not scale**. Nakagami's `x²~Gamma(shape=m, scale=Ω/m)` ⇒ pass **`rate = m/Ω`** everywhere (the inverse of the natural scale). Passing `Ω/m` is wrong-but-finite (no crash) — add convention-guard tests like `gamma.ts`.

### Load-bearing scipy↔HardFit mappings (emit side only, `gen_fixtures.py`)
- **student-t:** IDENTITY 1:1. `scipy.stats.t.fit(x)` → `(df, loc, scale)`; HardFit `{loc, scale, df}` (same three free params). Mode B freeze: `t(df, loc=loc, scale=scale)`. `scipyFitCall = stats.t.fit(arr)` (NO `floc`/`fscale`). `n_params=3`.
- **fisher-f:** `scipy.stats.f` is 4-param `f(dfn, dfd, loc, scale)`. PIN `floc=0, fscale=1`. `scipy.f.fit(x, floc=0, fscale=1)` → `(dfn, dfd, 0, 1)` (VERIFIED). Map `dfn→d1`, `dfd→d2`. Mode B freeze: `f(d1, d2, loc=0, scale=1)`. `n_params=2`.
- **inverse-gaussian (THE TRAP — the geometric-`loc=-1` of this batch):** `scipy.stats.invgauss(mu_s, loc, scale)` uses **`mu_s = mu/lambda`** and **`scale = lambda`** (NOT `mu` directly). Mode B freeze of HardFit `(mu, lambda)`: `invgauss(mu/lambda, loc=0, scale=lambda)`. `scipy.invgauss.fit(x, floc=0)` → `(mu_s, 0, scale)` ⇒ HardFit `lambda = scale`, `mu = mu_s*scale`. **VERIFIED** on `x=[1,2,0.5,1.5,3,0.8]`: scipy fit `(0.4055556, 0, 3.6164384)`; `mu_s*scale = 1.4666667 = mean(x)`; `scale = 3.6164384 = n/(Σ(1/x) − n/mean)`. `n_params=2`.
- **nakagami:** `scipy.stats.nakagami(nu, loc, scale)`; HardFit `m = nu`, **`Omega = scale²`** (scipy's scale multiplies x; Ω is a second-moment quantity). `scipy.nakagami.fit(x, floc=0)` → `(nu, 0, scale)` ⇒ emit `m=nu`, `Omega=scale**2`. Mode B freeze: `nakagami(m, loc=0, scale=sqrt(Omega))`. `n_params=2`. **Forgetting to square `scale` makes Ω off by a `sqrt`.**

## THE PARITY-GATE CONTRACT for iterative families (advisor-mandated, read before Task 3)

The **universal LL cross-check is THE gate**: `HardFit fitted LL ≥ scipy .fit LL − LOG_LIK_SLACK (1e-6)`. The loose iterative param diagnostic (`ITERATIVE_PARAM_RTOL = 1e-3`) is **informational only**.

**Why this matters and the rule:** scipy's `f.fit` (and `t.fit` on near-normal data) **under-converge**. When scipy loses, HardFit reaches a *better* optimum → the LL cross-check passes (HardFit ≥ scipy) **and** the params legitimately differ by >1e-3. A param-diagnostic mismatch *with an LL pass means scipy lost, not HardFit* — **do not debug HardFit in that case.** Therefore the parity test gets a documented skip-set for the tight diagnostic (NOT magic fixtures):

```ts
/** Params whose tight iterative diagnostic (ITERATIVE_PARAM_RTOL) is SKIPPED because scipy's
 *  own .fit under-converges / the likelihood is flat there, so HardFit legitimately differs while
 *  PASSING the LL cross-check (HardFit LL >= scipy LL). The LL gate is the real contract; this
 *  diagnostic is informational. Keyed by distribution name -> param keys to skip. */
const ITERATIVE_PARAM_DIAGNOSTIC_SKIP: Record<string, readonly string[]> = {
  [DistributionName.StudentT]: ['df'],     // near-normal data: LL flat in log(df); df not 1e-3-identifiable
  [DistributionName.FisherF]: ['d1', 'd2'], // scipy.f.fit under-converges even with floc/fscale pinned
}
```

Wire it into the existing iterative branch of the Mode A test (`scipy-parity.test.ts:232-238`): skip the `expectClose(value, ref, ITERATIVE_PARAM_RTOL)` when `(ITERATIVE_PARAM_DIAGNOSTIC_SKIP[distName] ?? []).includes(key)`. **The LL `expect(ll).toBeGreaterThanOrEqual(...)` always runs.**

**Fixture-data discipline (all iterative families):** use the project's existing **moderate-n** sample sizes (the n=25 / n=2000 convention), never adversarial tiny-n. At n=4–8 scipy's `t.fit` diverges to degenerate maxima (`df→0`, `scale→0`, spurious +LL) — feeding those to the gate would make HardFit's *correct* lower LL look like a failure. Generate Student-t fixtures from a real `t(df)` with **small-ish df (e.g. df=4 and df=8)** so `df` is identifiable; F fixtures from a real `F(d1,d2)` with moderate `(5,12)` / `(10,20)`.

- [ ] **Step 1: Add constants** to `constants.ts` (named, doc-commented, matching the `MAX_NEWTON_ITERATIONS` convention — zero magic numbers in `optimize.ts`):

```ts
// --- Nelder–Mead general minimizer (Batch D, src/engine/optimize.ts) ---
/** Hard cap on simplex iterations PER restart. Bounds the only inner loop. NO unbounded while-loop —
 *  this project lost a session to one in a beta test, so every loop here is a counted `for`. */
export const NM_MAX_ITERATIONS = 200
/** Hard cap on objective evaluations across the WHOLE minimize() call (all restarts). Independent of
 *  the iteration cap: a pathological objective can burn evals without advancing iterations, so the
 *  eval budget — checked INSIDE the safe-f wrapper — is the true freeze guard. */
export const NM_MAX_FUNCTION_EVALS = 2000
/** Restart-from-best count. A restart re-expands a FULL-SIZE fresh simplex around the incumbent best
 *  and re-searches; this escapes a collapsed simplex AND performs the final polish that clears the
 *  1e-6 LL parity gate (verified: restart-from-best reaches the closed-form MLE LL to machine zero). */
export const NM_MAX_RESTARTS = 2
/** ABSOLUTE simplex-size tolerance (max |coord − bestCoord| over all vertices). Absolute (not
 *  relative) because the parity gate is absolute in LL units. */
export const NM_X_TOL = 1e-10
/** ABSOLUTE objective-spread tolerance f(worst)−f(best). MUST be absolute and well below the 1e-6 LL
 *  gate; 1e-9 gives ~3 orders of headroom (verified to reach machine-zero LL gap). */
export const NM_F_TOL = 1e-9
/** Relative per-coordinate perturbation building the initial simplex from a NONZERO seed coord
 *  (vertex_i coord_i *= 1+this). scipy's `nonzdelt`; deterministic, no RNG. */
export const NM_INITIAL_STEP = 0.05
/** Absolute perturbation for a ZERO seed coord (else a relative bump of 0 gives a degenerate simplex).
 *  scipy's `zdelt`. */
export const NM_ZERO_STEP = 0.00025
/** Standard Nelder–Mead reflection / expansion / contraction / shrink coefficients. */
export const NM_REFLECTION = 1
export const NM_EXPANSION = 2
export const NM_CONTRACTION = 0.5
export const NM_SHRINK = 0.5
```

- [ ] **Step 3: Implement** `optimize.ts`:

```ts
export type Objective = (x: readonly number[]) => number
export interface MinimizeResult { x: number[]; fx: number; iterations: number; converged: boolean }
export interface NelderMeadOptions {
  maxIterations?: number; maxFunctionEvals?: number; maxRestarts?: number
  xTol?: number; fTol?: number; initialStep?: number; zeroStep?: number
  reflection?: number; expansion?: number; contraction?: number; shrink?: number
}
export function minimize(f: Objective, x0: readonly number[], options?: NelderMeadOptions): MinimizeResult
```

  Algorithm (precise):
  - **safeF wrapper** (the ONLY place `f` is called): a closure eval counter; if it reached `maxFunctionEvals`, signal budget-exhausted (caller early-returns best-so-far) and do NOT call `f`. Else call `f(x)`, increment; if result is `NaN`, `+Inf`, **or `−Inf`** → return `+Infinity`. *(Comment the `−Inf→+Inf` map as intentional: a genuine `−Inf` negLL, e.g. σ→0 overfit, is rejected like NaN so the simplex never collapses onto a degenerate maximum.)*
  - **Deterministic initial simplex** (n+1 vertices around `x0=v[0]`): for `i in 0..n−1`, `v[i+1]=copy(x0)`; if `x0[i]!==0` set `v[i+1][i]=x0[i]*(1+initialStep)` else `=zeroStep`. No RNG. Works for n=1.
  - **Per-restart loop** `for it=0; it<maxIterations; it++`: eval+cache `fv[]`; sort vertices ascending by `fv` with a **deterministic index tie-break** (comparator returns the index order on equal f). Convergence requires **BOTH** `fv[worst]−fv[best] ≤ fTol` AND `max over vertices/coords |v[i][j]−v[best][j]| ≤ xTol`. Centroid `c` = mean of all-but-worst. Reflection `xr=c+α(c−worst)`; accept/expand/contract/shrink per standard NM (outside vs inside contraction; shrink is a bounded `for k=1..n`). After every `safeF`, if the eval budget is exhausted, stop and return current best with `converged=false`.
  - **Outer driver** `for r=0; r<=maxRestarts; r++`: build a fresh full-size simplex around `bestX`; run the per-restart loop; if a restart improved `bestF` by `< fTol` AND converged (or `r===maxRestarts`) set `converged=true` and stop. Accumulate `iterations`. Return `{x:bestX, fx:bestF, iterations, converged}`.
  - **Invariant (state in a comment):** ZERO while-loops — three bounded `for`s (restart, iteration, shrink) + the global eval tripwire inside `safeF`. No path can spin without consuming an iteration or an eval.
