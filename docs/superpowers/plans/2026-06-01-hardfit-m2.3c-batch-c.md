**The `Distribution.logpdf` method delegates to `@stdlib`'s `logpmf`** for these (the interface slot is named `logpdf` but carries log-PMF mass; `selection.logLik` sums it correctly). **`@stdlib` `logpmf` returns `-Infinity` at non-integer / out-of-support x** (verified) — the natural backstop, but each `fit()` ALSO guards integers explicitly for a clean error.

**Load-bearing scipy↔HardFit mappings (emit side only, `gen_fixtures.py`):**
- poisson: IDENTITY — `scipy.stats.poisson(mu=λ, loc=0)`, HardFit `{lambda: λ}`.
- geometric: **`scipy.stats.geom(p, loc=-1)`** — scipy.geom is native `{1,2,…}` (trials); `loc=-1` shifts it to `{0,1,…}` (failures) to match `@stdlib`. WITHOUT `loc=-1` every value is off by one and the gate fails. HardFit `{p}` (p value identical).
- negative-binomial: IDENTITY — `scipy.stats.nbinom(n=r, p=p, loc=0)` (both use 0-based failure counts), HardFit `{r, p}`.
- discrete-uniform: **`scipy.stats.randint(low=a, high=b+1)`** — scipy.randint is half-open `{low,…,high−1}`; the **`+1` on `high`** encodes `@stdlib`'s inclusive `b`. HardFit `{a, b}` = `{low, high−1}`.

**Caveat to document (advisor #3):** On integer data, density-based fits (Normal, …) report a *density* AICc and discrete fits a *PMF* AICc — different base measures, so the cross-ranking is approximate (for unit-spaced counts density×1 ≈ PMF, which is why tools list them together). Add a one-line note next to the Lilliefors/Chernoff-Lehmann caveats in `gof.ts`/the strategy doc.

## THE DISCRETE CHI-SQUARE BINNING (the #1 correctness risk — spec'd to determinism)

This algorithm MUST be implemented **identically** in `gof.ts` (`chiSquaredGofDiscrete`) and `gen_fixtures.py` (`chi_squared_binning_discrete`) — a divergence yields a plausible-but-wrong statistic. The parity gate pins the **bin edges + observed + expected counts**, not just the statistic.

**Inputs:** sorted unique integer support present in the data is NOT used; instead enumerate the distribution's support from its lower bound upward. `pmf(v) = exp(logpmf(v))`, `cdf(v)`, `nParams`.

**Algorithm (deterministic):**
1. Let `lo` = the distribution's support minimum (0 for poisson/geometric/nbinom; `a` for discrete-uniform).
2. Build raw cells for consecutive integers `v = lo, lo+1, lo+2, …`: each cell is the single value `v` with `expected_v = n · pmf(v)` and `observed_v = #{x_i == v}`. Stop enumerating at `vMax` = the largest of (data max, the smallest `v` whose upper-tail `n·(1 − cdf(v)) < MIN_EXPECTED_PER_BIN`). For discrete-uniform, `vMax = b` exactly (finite support).
3. **Upper-tail merge (direction: merge upward into a single tail cell):** the final cell is `{≥ t}` for the smallest `t` such that the remaining tail `n·(1 − cdf(t−1))` would otherwise be < `MIN_EXPECTED_PER_BIN` when split further; its `expected = n·(1 − cdf(t−1))` and `observed = #{x_i ≥ t}`. Concretely: accumulate single-value cells while `expected_v ≥ MIN_EXPECTED_PER_BIN`; once a value's expected drops below the threshold, collapse it and everything above into ONE tail cell `{≥ v}` with `expected = n·(1 − cdf(v−1))`, `observed = #{x_i ≥ v}`.
4. **Lower-tail merge (same rule, head):** if the first cell(s) have `expected < MIN_EXPECTED_PER_BIN`, merge consecutive head cells into `{≤ s}` until `expected ≥ MIN_EXPECTED_PER_BIN` (expected of `{≤ s}` = `n·cdf(s)`). (For the chosen fixtures with small λ the head is usually fine; implement the merge for correctness.)
5. `k` = number of cells after merging. `X² = Σ (O_j − E_j)² / E_j`. `df = k − 1 − nParams`. `pValue = df ≥ 1 ? 1 − χ²cdf(X², df) : NaN`.

**Edge handling:** cells are half-open on the merged tails; single-value cells are exact integer matches (`x == v`). No floating quantile edges (unlike continuous). Reuse `MIN_EXPECTED_PER_BIN = 5` and the `χ²cdf` import already in `gof.ts`.

**TS signature:**
```ts
export function chiSquaredGofDiscrete(
  data: readonly number[],
  pmf: (x: number) => number,   // exp(logpmf) — P(X = v)
  cdf: (x: number) => number,   // F(v) for tail expecteds
  supportMin: number,           // 0, or a for discrete-uniform
  supportMax: number,           // +Infinity (unbounded), or b for discrete-uniform
  nParams: number,
): { statistic: number; df: number; bins: number; pValue: number }
```

The Python `chi_squared_binning_discrete(data, pmf, cdf, support_min, support_max, n_params)` mirrors this exactly. **Both emit the cell edges + observed + expected** so the parity test can pin them.

### Task 3: Poisson — closed-form, k=1
**MLE:** `lambda = mean(data)`. Guards: integer (`data.some(v => !Number.isInteger(v))` → throw `'poisson requires integer counts'`), `v < 0` → throw, `!(lambda > 0)` (all zeros) → throw. `support(){ return {min:0, max:Infinity} }`. `logpdf(x,p)=logpmf(x, p.lambda)`, `cdf`, `quantile(prob, p.lambda)`. Sampler `poissonSampler.factory(lambda,{seed})`. gate closed-form-params. Convention guard: `logpmf(x,λ)=x·ln λ − λ − ln(x!)`; for λ=2, x=3: `logpdf(3,{lambda:2}) === 3*Math.log(2) - 2 - Math.log(6)` to 1e-9.

`build_poisson` (gen_fixtures): analytic `lambda_a = float(np.mean(x))`; `rv = scipy.stats.poisson(mu=lambda_a, loc=0)`; discrete `gof_block` (logpmf + discrete binning); Mode-A `form="closed-form"`, params `{lambda}`, `logLik = sum(rv.logpmf(x))`, grid-scan floor (Task 7). closed-form gate.

### Task 4: Geometric — closed-form, k=1
**MLE:** `p = 1/(1 + mean(data))` (the `{0,1,…}` failures convention — do NOT use 1/mean). Guards: integer, `v < 0`, `mean` finite. `support(){min:0,max:Infinity}`. `{p}` → `logpmf(x, p.p)` etc. Sampler `geometricSampler.factory(p,{seed})`. Convention guard: `logpmf(x,p)=x·ln(1−p)+ln p`; for p=0.4, x=2: `logpdf(2,{p:0.4}) === 2*Math.log(0.6) + Math.log(0.4)` to 1e-9. `build_geometric`: analytic `p_a = 1/(1+np.mean(x))`; **`rv = scipy.stats.geom(p_a, loc=-1)`** (the load-bearing shift); discrete gof_block; closed-form gate.

### Task 5: Negative-Binomial — iterative-1d, k=2, LL-only
**MLE:** profile `p = r/(r + mean)`; solve `r` by 1-D Newton on `g(r) = Σ[ψ(x_i+r) − ψ(r)] + n·ln(r/(r+x̄))`, `g'(r) = Σ[ψ₁(x_i+r) − ψ₁(r)] + n·(1/r − 1/(r+x̄))` (`g` decreasing → unique root WHEN overdispersed). MoM seed `r0 = x̄²/(s² − x̄)` (sample variance `s²`). **CRITICAL guard (advisor + research):** if `s² ≤ x̄` (under/equidispersed) the MLE diverges (`r → ∞`, Poisson limit) → throw `'negative-binomial: no finite MLE (data not overdispersed)'` BEFORE Newton. Also integer + `v<0` guards, and a Newton convergence/finite guard (converge-or-throw, like chisquare). `support(){min:0,max:Infinity}`. `{r,p}` → `logpmf(x, p.r, p.p)` etc. Sampler `negativeBinomialSampler.factory(r,p,{seed})`. **LL-only gate.** Convention guard: hand-written `logpmf` with `gammaln` (`ln Γ(x+r) − ln Γ(r) − ln x! + r ln p + x ln(1−p)`) at asymmetric r,p. `build_negative_binomial`: analytic Newton MLE in numpy (NOT scipy.fit — none exists); `rv = scipy.stats.nbinom(r, p, loc=0)`; Mode-A `form="iterative"`, LL from `rv.logpmf`, **grid-scan floor over (r,p)** as the independent cross-check.

### Task 6: Discrete-Uniform — closed-form, k=2
**MLE:** `a = min(data)`, `b = max(data)` (single-pass, NOT `Math.min(...data)`). Guards: integer, `!(b > a)` → degenerate throw, finite. `support(){return {min:a, max:b}}` (from params). `{a,b}` → `logpmf(x, p.a, p.b)` etc. Sampler `discreteUniformSampler.factory(a,b,{seed})`. closed-form-params gate. Convention guard: `logpmf(x,a,b)=−ln(b−a+1)` for x in support; for a=1,b=6,x=3: `logpdf(3,{a:1,b:6}) === -Math.log(6)` to 1e-9. `build_discrete_uniform`: analytic `a=int(min), b=int(max)`; **`rv = scipy.stats.randint(low=a, high=b+1)`** (the load-bearing `+1`); discrete gof_block; closed-form gate.
