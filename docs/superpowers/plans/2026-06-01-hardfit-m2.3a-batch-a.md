# HardFit M2.3 Batch A — Drop-in Distributions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Grow the fitted-distribution catalog from 5 → 13 by adding 8 "drop-in" continuous distributions (Uniform, Rayleigh, Pareto Type I, Laplace, Logistic, Gumbel max, Cauchy, Fréchet), each verified against the scipy parity gate, with samplers for the bootstrap.

**Architecture:** Pure `src/engine/distributions/<name>.ts` modules implementing the `Distribution` interface (fit/logpdf/cdf/quantile) over `@stdlib` per-function packages, a self-built MLE layer, a `sampling.ts` sampler case + convention-guard test per distribution, a `gen_fixtures.py` builder per distribution, and registry/`DistributionName` wiring. The scipy fixture gate is the numerical verification.

**Tech Stack:** TypeScript (engine is pure, no DOM/React), `@stdlib/stats-base-dists-*` + `@stdlib/random-base-*`, Vitest + fast-check, Python/numpy/scipy fixture generator (local only).

## Task 1: Gate enhancement — universal `LL ≥ scipy.fit` cross-check

**Why:** For closed-form families the gate asserts params against a *numpy-analytic* reference. A formula wrong identically in the Python emit and the TS code would self-cancel and pass green. Fix: assert HardFit's fitted log-likelihood ≥ the log-likelihood of an **independent `scipy.fit`** result (minus slack) for **every** family. scipy's optimizer does not share our formula, so a real formula bug yields suboptimal params → LL below scipy → fails. This degrades gracefully at boundary MLEs (uniform/Pareto) where a gradient≈0 check would misfire.

**Files:** `scripts/gen_fixtures.py`, `tests/fixtures/scipy-r/scipy-parity.test.ts`

- [ ] **Step 1: In `gen_fixtures.py`, source `modeA.logLik` from the `scipy.fit` frozen dist for ALL families.**

Today the closed-form builders set `modeA.logLik` from the analytic `rv_a`. Change each closed-form builder (`build_normal`, `build_lognormal`, `build_exponential`, and the new closed-form builders) so `modeA.logLik` = `log_lik(data, rv)` where `rv` is the **`scipy.fit`-derived** frozen dist (the same `rv` used for Mode B), NOT the analytic `rv_a`. Keep `modeA.params` = the analytic MLE (for the closed-form 1e-9 param check). For iterative builders `modeA.logLik` already comes from `scipy.fit` — no change. (For normal/exponential/lognormal `scipy.fit` ≡ analytic, so the emitted value is unchanged; the change only makes the reference *independent of our formula*.)

- [ ] **Step 2: In `scipy-parity.test.ts`, assert the LL cross-check UNIVERSALLY (both branches).**

Move the `expect(ll).toBeGreaterThanOrEqual(fx.modeA.logLik - LOG_LIK_SLACK)` assertion OUT of the iterative-only `else` and run it for every family (closed-form AND iterative), in addition to the existing closed-form param 1e-9 check. Concretely, in the `fit-from-data` test:

```ts
const fitted = dist.fit(fx.data)
const ll = logLik(fx.data, (x) => dist.logpdf(x, fitted))
// Universal independent cross-check: HardFit must reach scipy.fit's LL (immune to a
// formula bug shared between the Python emit and the TS code — scipy's optimizer doesn't
// share our formula, so suboptimal params land below scipy's LL and fail here).
expect(ll).toBeGreaterThanOrEqual(fx.modeA.logLik - LOG_LIK_SLACK)
if (isClosedForm) {
  for (const [key, ref] of Object.entries(fx.modeA.params)) {
    const value = fitted[key]
    expect(value, `missing fitted param "${key}"`).toBeTypeOf('number')
    expectClose(value as number, ref, PARITY_RTOL)
  }
} else {
  for (const [key, ref] of Object.entries(fx.modeA.params)) {
    const value = fitted[key]
    if (typeof value === 'number') expectClose(value, ref, ITERATIVE_PARAM_RTOL)
  }
}
```

## Tasks 3–10: the 8 distributions

Each distribution is one task. **Follow the existing templates:** closed-form → `normal.ts`/`exponential.ts`; iterative 1-D Newton → `weibull.ts`/`gamma.ts`. Every module copies the standard `type XParams = {...}` alias + one `p as XParams` narrowing per density function + the `FittedParams`-DTO comment block. Every `fit()` validates support + a degeneracy guard mirroring `normal`'s zero-variance throw. Each task adds: the `distributions/<name>.ts` module, the `<name>.test.ts` (convention guard + cdf/quantile round-trip + degeneracy + `k`/`kind`), the `DistributionName` entry, the registry line in `distributions/index.ts`, the `sampling.ts` case + `sampling.test.ts` guard, the `gen_fixtures.py` `build_<name>` + `BUILDERS` entry, and (closed-form only) the `CLOSED_FORM_NAMES` entry in the parity test.

> Convention-guard test (mandatory for every distribution, like gamma/weibull): compare `logpdf` at a known point to the **elementary closed-form density** written out by hand — this catches a wrong `@stdlib` arg slot that self-consistency tests miss.

### Task 3: Uniform (continuous) — closed-form, k=2

**MLE:** `a = Math.min(...data)`, `b = Math.max(...data)`. Degeneracy guard: `if (!(b > a)) throw new Error('uniform: degenerate (max <= min, zero width)')`; `MIN_SAMPLE_SIZE = 2`. **Params** `{a, b}` → `logpdf(x, a, b)`, `cdf(x, a, b)`, `quantile(p, a, b)`, `uniform.factory(a, b, {seed})`. **gate:** closed-form-params (add to `CLOSED_FORM_NAMES`). **Sampler guard:** moment (mean≈(a+b)/2, var≈(b−a)²/12).

`build_uniform` (gen_fixtures): `loc, scale = stats.uniform.fit(arr); rv = stats.uniform(loc=loc, scale=scale)`. **LOAD-BEARING mapping:** `fixed = {"a": float(loc), "b": float(loc + scale)}` — `b` is `loc + scale`, the absolute max, NOT the raw `scale`. Mode A analytic: `a_a = float(np.min(arr)); b_a = float(np.max(arr))`; `params = {"a": a_a, "b": b_a}`; `modeA.logLik = log_lik(data, rv)` (the scipy.fit rv — independent); `aicc_or_sentinel(ll, 2, n)`.

### Task 4: Rayleigh — closed-form, k=1

**MLE:** `sigma = Math.sqrt(data.reduce((s,x)=>s+x*x,0) / (2*n))`. Support x≥0: `if (data.some(v => v < 0)) throw new Error('rayleigh requires all x >= 0')`; then `if (!(sigma > 0)) throw new Error('rayleigh: degenerate (sum of squares is zero)')`. `MIN_SAMPLE_SIZE = 1`. **Params** `{sigma}` → `logpdf(x, sigma)` etc.; `rayleigh.factory(sigma, {seed})`. **gate:** closed-form-params. **Sampler guard:** moment (mean≈σ√(π/2)).

`build_rayleigh`: Mode B `loc, scale = stats.rayleigh.fit(arr, floc=0); rv = stats.rayleigh(loc=0, scale=scale); fixed = {"sigma": float(scale)}` (IDENTITY — sigma = scale, do NOT invert). Mode A analytic: `sigma_a = float(np.sqrt(np.sum(arr**2)/(2*len(arr)))); params = {"sigma": sigma_a}; modeA.logLik = log_lik(data, rv)` (scipy.fit rv); `aicc_or_sentinel(ll, 1, n)`.

### Task 5: Pareto (Type I) — closed-form, k=2

**MLE:** `const xm = Math.min(...data); const s = data.reduce((acc,x)=>acc+Math.log(x/xm),0); if (!(s > 0)) throw new Error('pareto: degenerate (all values equal)'); const alpha = n / s; return { shape: alpha, scale: xm }`. Support x>0: `if (data.some(v => v <= 0)) throw new Error('pareto requires all x > 0')`. `MIN_SAMPLE_SIZE = 2`. **Params** `{shape, scale}` → `logpdf(x, shape, scale)` (alpha=shape slot, beta=scale=xm slot), `quantile`, `cdf`; `pareto1.factory(shape, scale, {seed})`. **gate:** closed-form-params. **Sampler guard:** median/IQR (median = xm·2^(1/α); heavy tail, no variance for α≤2).

`build_pareto`: Mode B uses analytic params (scipy.pareto.fit is a fragile numerical optimizer — do NOT use it for the param reference): `xm = float(np.min(arr)); alpha = float(len(arr) / np.sum(np.log(arr/xm))); rv = stats.pareto(alpha, loc=0, scale=xm); fixed = {"shape": alpha, "scale": xm}`. Mode A: `params = {"shape": alpha, "scale": xm}`; `modeA.logLik = log_lik(data, rv_scipyfit)` where `rv_scipyfit` is from `stats.pareto.fit(arr, floc=0)` for the **independent** LL cross-check (HardFit's analytic LL ≥ scipy.fit LL holds). Mark `gateType` closed-form-params (param check vs analytic). `aicc_or_sentinel(ll, 2, n)`.

> Note: Pareto's `xm = min(x)` is a boundary estimator — its standard error is not asymptotically normal. Not relevant to fitting/ranking (M2.3) but flag if/when SEs are surfaced for Pareto.

### Task 6: Laplace — closed-form formula, LL-only gate, k=2

**MLE:** `mu = median(sorted data)` (midpoint of the two middle order stats for even n); `b = mean(|x − mu|)`. Degeneracy: `if (!(b > 0)) throw new Error('laplace: degenerate (zero scale)')`. `MIN_SAMPLE_SIZE = 2`. **Params** `{mu, b}` → `logpdf(x, mu, b)` etc.; `laplace.factory(mu, b, {seed})`. **gate: LL-only** (even-n median is non-unique: the likelihood is flat in μ across the central interval — a param gate would be spurious). **Sampler guard:** moment (mean≈μ, var≈2b²).

`build_laplace`: `loc, scale = stats.laplace.fit(arr)` — **NO `floc`** (location is free; copying the `floc=0` pattern would force μ=0 and corrupt the oracle). `rv = stats.laplace(loc=loc, scale=scale); fixed = {"mu": float(loc), "b": float(scale)}` (direct, no inversion). Mode A `form="iterative"` (LL gate): `modeA.logLik = log_lik(data, rv)`, `params = {"mu": float(loc), "b": float(scale)}` (loose diagnostic), `aicc_or_sentinel(ll, 2, n)`. Do NOT add laplace to `CLOSED_FORM_NAMES`.

### Task 7: Logistic — iterative 2-D, LL-only, k=2

**MLE:** no closed form; log-likelihood is strictly log-concave ⇒ unique max. Let `z_i=(x_i−μ)/s`, `F_i=1/(1+e^{−z_i})`. Score: `Σ(2F_i−1)=0` and `Σ z_i(2F_i−1)=n`. **Seed (MoM):** `μ0=mean(x)`, `s0=sd(x)·√3/π`. Solve with 2-D Newton on the gradient using the negative Hessian (or alternate 1-D Newton on μ then s), damping to keep `s>0`; reuse `MAX_NEWTON_ITERATIONS`/`NEWTON_REL_TOL`. Degeneracy: zero sample variance → throw `'logistic: degenerate (zero variance)'`. **Params** `{mu, s}` → `logpdf(x, mu, s)` etc.; `logistic.factory(mu, s, {seed})`. **gate: LL-only.** **Sampler guard:** moment (var≈s²π²/3).

`build_logistic`: `loc, scale = stats.logistic.fit(arr)` (no floc); `rv = stats.logistic(loc=loc, scale=scale); fixed = {"mu": float(loc), "s": float(scale)}` (direct). Mode A `form="iterative"`: `modeA.logLik = log_lik(data, rv)`, params loose, aicc. Convention-guard test: `logpdf` vs `e^{−z}/(s(1+e^{−z})²)`.

### Task 8: Gumbel (max) — iterative 1-D, LL-only, k=2

**MLE (profiled):** solve 1-D for β then μ closed-form. Score `g(β)=x̄ − β − Σ x_i e^{−x_i/β} / Σ e^{−x_i/β} = 0`, monotone decreasing. **Seed:** `β0 = sd(x)·√6/π`. **Newton with analytic derivative** using `S0=Σe^{−x/β}, S1=Σx e^{−x/β}, S2=Σx² e^{−x/β}`: `g'(β) = −1 − (S2·S0 − S1²)/(β²·S0²)` (<0). **Numerical stability (load-bearing):** compute `e^{−x/β}` with a max-shift `z=−x/β, zmax=max(z), w=e^{z−zmax}`; the constant cancels in the `S1/S0` ratio. **Location:** `μ = −β·(ln(mean(w)) + zmax)`. Damp β/2 on non-positive/non-finite step; reuse Newton constants. Degeneracy: zero spread → throw `'gumbel: degenerate (zero spread)'`. **Params** `{mu, beta}` → `logpdf(x, mu, beta)` etc.; `gumbel.factory(mu, beta, {seed})`. **gate: LL-only** (iterative; the universal LL cross-check + a loose param diagnostic apply). **Sampler guard:** moment.

`build_gumbel`: `loc, scale = stats.gumbel_r.fit(arr)` — **`gumbel_r` (MAX/right-skewed), NO `floc`.** Verified `@stdlib gumbel` matches `gumbel_r` (CDF `exp(−exp(−(x−μ)/β))`). `rv = stats.gumbel_r(loc=loc, scale=scale); fixed = {"mu": float(loc), "beta": float(scale)}`. Mode A `form="iterative"`: `modeA.logLik = log_lik(data, rv)`, params loose, aicc. Do NOT pair with `gumbel_l`.

### Task 9: Cauchy — iterative 2-D, multimodal, LL-only, k=2

**MLE:** no closed form; likelihood is **multimodal**. Maximize `L(x0,γ) = −n ln π − n ln γ − Σ ln(1 + r_i²)`, `r_i=(x_i−x0)/γ`. **Seed (robust, REQUIRED — Cauchy has no moments):** `x0_0 = median`, `γ0 = (Q3−Q1)/2` (half-IQR). **Optimizer:** IRLS fixed-point with weights `w_i = 1/(γ² + (x_i−x0)²)`: `x0 ← Σw_i x_i / Σw_i`; update `γ` to satisfy `Σ r_i²/(1+r_i²)=n/2` (equivalently `γ² ← 2 Σ w_i (x_i−x0)² / Σ w_i`... use the standard Cauchy IRLS update); iterate to a tight tolerance. **MULTI-START (defeats multimodality):** run the optimizer from a few seeds — `{median, trimmed-mean, median±half-IQR}` — and return the solution with the highest log-likelihood. This guarantees HardFit's LL ≥ scipy's single-start fit. Degeneracy: zero spread (IQR=0) → throw `'cauchy: degenerate (zero spread)'`. **Params** `{x0, gamma}` → `logpdf(x, x0, gamma)` etc.; `cauchy.factory(x0, gamma, {seed})`. **gate: LL-only.** **Sampler guard: median/IQR** (no mean/variance — assert empirical median≈x0, empirical IQR≈2γ).

`build_cauchy`: `loc, scale = stats.cauchy.fit(arr)` — **NO `floc`** (the floc=0 trap centers the median at 0 and corrupts the oracle on positive data). `rv = stats.cauchy(loc=loc, scale=scale); fixed = {"x0": float(loc), "gamma": float(scale)}`. Mode A `form="iterative"`: `modeA.logLik = log_lik(data, rv)`, params loose, aicc.

> Contingency: if the LL gate flakes on any dataset (most likely `tiny_3`, n=3), strengthen the multi-start (add more seeds / a small grid) before considering deferral. The multi-start should make HardFit ≥ scipy on every dataset.

### Task 10: Fréchet — iterative 1-D via reciprocal-Weibull, LL-only, k=2

**MLE (m≡0):** use the identity `X~Fréchet(α,s) ⇔ 1/X~Weibull(shape=α, scale=1/s)`. Fit by feeding reciprocals `y_i=1/x_i` into HardFit's verified Weibull Newton, then map back: `shape = k_weibull(y)`, `scale = 1 / scale_weibull(y)`. (Reuse `weibull.fit` internally or replicate its loop on `y`.) Support x>0: `if (data.some(v => v <= 0)) throw new Error('frechet requires all x > 0')`; zero-log-variance guard like gamma. `MIN_SAMPLE_SIZE = 2`. **Params** `{shape, scale}` (m fixed 0, not stored) → `logpdf(x, shape, scale, 0)`, `cdf(x, shape, scale, 0)`, `quantile(p, shape, scale, 0)`; `frechet.factory(shape, scale, 0, {seed})`. **gate: LL-only.** **Sampler guard: median/IQR** (variance infinite for α≤2; canonical data fits α≈1.2).

`build_frechet`: `c, _loc, scale = stats.invweibull.fit(arr, floc=0); rv = stats.invweibull(c, loc=0, scale=scale); fixed = {"shape": float(c), "scale": float(scale)}` (SCALE slot, no inversion). Mode A `form="iterative"`: `modeA.logLik = log_lik(data, rv)`, params loose, aicc. Convention-guard test: `@stdlib frechet logpdf` vs `α/s·((x−m)/s)^(−1−α)·exp(−((x−m)/s)^(−α))` with m=0.
