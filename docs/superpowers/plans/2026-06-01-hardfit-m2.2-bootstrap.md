# HardFit M2.2 — Parametric bootstrap (BCa/percentile parameter CIs + Lilliefors-correct GoF p-values) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add a parametric bootstrap to HardFit: **confidence intervals** (percentile + BCa) for each fitted parameter, and **statistically valid p-values** (the Lilliefors-correct parametric-bootstrap p) for KS / Anderson-Darling / Cramér-von Mises — computed in the Web Worker for the top-k ranked fits, chunked + cancellable, and shown in the UI. These are two more things EasyFit lacks.

**Architecture:** Extend the pure `src/engine/` — `sampling.ts` (seedable per-distribution samplers, reusing `@stdlib/random-base-*`, conventions matching the M1 densities) and `bootstrap.ts` (one *fused* B-iteration loop that simulates from the fitted distribution, refits via the existing `Distribution.fit`, and produces BOTH the parameter replicates for CIs AND the bootstrap GoF statistics for p-values; plus a jackknife pass for the BCa acceleration). The worker exposes `bootstrapTopFits`; the React UI auto-runs it in the background for the top-k after the (instant) fit, with a progress bar + cancel, then shows CIs + the rigorous bootstrap p-values. Reuses M2.1's `ksStatistic`/`adStatistic`/`cramerVonMises`. Builds on M2.1 (live).

**Tech Stack:** TypeScript strict, `@stdlib/random-base-*` (0.2.2) + `@stdlib/random-base-mt19937` (0.2.3) + the M2.1 normal cdf/quantile for BCa, Vitest + fast-check, Comlink worker.

> ### Locked technical facts (verified 2026-06-01 via the M2 workflow — do not re-derive)
> **Samplers (CommonJS export=, pin individually; the random family is at 0.2.x, NOT 0.3.1):** `@stdlib/random-base-{normal,lognormal,exponential,gamma,weibull}@0.2.2`, `@stdlib/random-base-mt19937@0.2.3`. Each has `.factory(...params, { seed })` → a stateful reproducible generator. **Conventions match the M1 stored params 1:1:** normal `factory(mu, sigma)` (σ=SD), lognormal `factory(mu, sigma)` (log-scale), exponential `factory(rate)` (RATE), **gamma `factory(shape, rate)` (RATE — pass `p.rate`, NOT `p.scale`)**, **weibull `factory(shape, scale)` (SCALE — NOT rate)**. Same slot-traps as the densities → add convention-guard tests (large-n empirical mean/var vs closed form).
> **Reproducibility:** seed ONCE per distribution (derive a per-distribution seed from a master seed, e.g. `masterSeed ^ perNameSalt`), then draw the whole `n·B` stream from the SAME stateful generator. **NEVER rebuild the factory inside the loop** (→ identical samples, a silent statistical bug). Expose the master seed in the result for reproducibility/testing.
> **Percentile CI:** sort the B replicates of a parameter; CI = `[Q(α/2), Q(1−α/2)]` using R type-7 linear interpolation: `h=(B−1)p; lo=⌊h⌋; v[lo]+(h−lo)(v[lo+1]−v[lo])`.
> **BCa (per scalar parameter — univariate; gamma's shape and rate get SEPARATE intervals):** `z0 = Φ⁻¹(#{θ*_b < θ̂}/B)` (STRICT `<`, original θ̂). Acceleration from a JACKKNIFE on the ORIGINAL data: `θ_(i)` = refit with obs i deleted; `θ̄ = mean θ_(i)`; `a = Σ(θ̄−θ_(i))³ / (6·[Σ(θ̄−θ_(i))²]^{3/2})`. Adjusted: `a1 = Φ(z0 + (z0+z_{α/2})/(1−a(z0+z_{α/2})))`, `a2 = Φ(z0 + (z0+z_{1−α/2})/(1−a(z0+z_{1−α/2})))`; CI = `[Q(a1), Q(a2)]`. **Edge guards:** if `#{θ*<θ̂} ∈ {0,B}` (z0 = ±∞) OR the denominator `Σ(...)²=0`, FALL BACK to the percentile CI and flag it. **Invariant (unit test):** `a=0, z0=0` ⇒ `a1=α/2, a2=1−α/2` (BCa = percentile). Uses `@stdlib/stats-base-dists-normal-cdf` (Φ) + `-normal-quantile` (Φ⁻¹), both already deps.
> **Bootstrap GoF p-value (the Lilliefors fix):** for the observed `S_obs` (KS/AD/CvM at θ̂), simulate B samples from `F(·;θ̂)`, **REFIT each** to θ*_b, recompute `S*_b` against the REFITTED CDF; `p = (1 + #{S*_b ≥ S_obs}) / (B + 1)`. Larger statistic = worse fit (right tail). The `+1` form is never exactly 0. Use B=999 (B+1=1000, good p-value discreteness; adequate BCa).
> **One FUSED loop** does CIs + all three p-values; the ONLY extra pass is the jackknife (n leave-one-out refits, once per distribution, independent of B). Refit may throw on a degenerate synthetic sample → `try/catch` and skip that replicate.
> **Performance/responsiveness (Comlink worker):** run ONLY for the top-k (k=3) AICc fits. Chunk ~50 iterations: post a progress fraction + `await` a 0ms timer so the worker services messages — these are also the **cancellation checkpoints**. **Cancellation is cooperative** (AbortSignal is NOT transferable through Comlink — same as M1's worker): a proxied flag/`cancel()` the worker polls each chunk. Jackknife O(n²) for weibull is a freeze hazard → **cap n for BCa** (above a threshold, skip the acceleration → percentile CI) or use O(1) sufficient-stat leave-one-out for normal/exp/lognormal/gamma.

```typescript
import normalSampler from '@stdlib/random-base-normal'
import lognormalSampler from '@stdlib/random-base-lognormal'
import exponentialSampler from '@stdlib/random-base-exponential'
import gammaSampler from '@stdlib/random-base-gamma'
import weibullSampler from '@stdlib/random-base-weibull'
import { DistributionName, type FittedParams } from './types'

/** Seeded iid sampler in HardFit's param convention. Seed once; call repeatedly (advances one stream). */
export function makeSampler(name: string, p: FittedParams, seed: number): () => number {
  switch (name) {
    case DistributionName.Normal: return normalSampler.factory(p.mu as number, p.sigma as number, { seed })
    case DistributionName.Lognormal: return lognormalSampler.factory(p.mu as number, p.sigma as number, { seed })
    case DistributionName.Exponential: return exponentialSampler.factory(p.rate as number, { seed }) // RATE
    case DistributionName.Gamma: return gammaSampler.factory(p.shape as number, p.rate as number, { seed }) // shape, RATE
    case DistributionName.Weibull: return weibullSampler.factory(p.shape as number, p.scale as number, { seed }) // shape, SCALE
    default: throw new Error(`makeSampler: no sampler for '${name}'`)
  }
}
```
